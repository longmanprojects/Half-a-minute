# 30 Seconds – Travel Edition
## Project Synopsis & Running Brief

### What We're Building
A mobile-first web app called "30 Seconds – Travel Edition" — a digital version of the hugely popular South African party board game 30 Seconds. The app is designed to be pulled out when friends want to play but don't have the physical game with them. It replicates all core gameplay mechanics in a modern, mobile-friendly format.

---

### The Game — How It Works

- Players split into teams (minimum 2, no maximum)
- Each team has individual players whose names are entered at setup
- Teams take turns — on each turn, one player from the active team is the describer
- The describer has 30 seconds to get their teammates to guess as many of the 5 words/names on a card as possible — without saying the word itself
- Score = number of correctly guessed words per turn, accumulated across rounds
- First team to reach the target score wins (target is chosen by players before the game starts — e.g. 30, 50, 100 points)
- There is no physical board — points replace the board's movement mechanic

### Design Direction

#### Colour Palette
| Role | Hex | Usage |
|------|-----|-------|
| Pastel yellow | `#F5E06E` | Dominant card colour, key UI accent |
| Powder blue | `#7BB8D4` | Card backs, secondary UI elements |
| Deep navy | `#1A1F3A` | Primary background (mimics the game board) |
| Off-white/cream | — | Text on yellow elements |
| White | — | Text on blue elements |
| Warm red/amber | — | Sparingly: timer running low, CTAs only |

#### Aesthetic
Modern but nostalgic. Bold, slightly retro typography. Should feel like a reimagined board game — not a generic quiz app. Think "what if the physical 30 Seconds game got a slick app redesign". The UI should invoke nostalgia for the original game while feeling current and polished. It should feel like something you'd genuinely pull out at a braai.
