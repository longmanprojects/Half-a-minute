# Startup Instructions

Paste these three commands into Terminal to resume the project:

```
export PATH="$HOME/node/bin:$PATH"
cd "/Users/admin/Claude Projects/Half a minute"
npm run dev
```

Then open your browser to the URL Vite prints (usually http://localhost:5173).

To reopen Claude Code, paste the above first, then open a new Terminal tab and run:

```
claude
```
